# EventDock 에이전트 지침

[English](AGENTS.md) | [한국어](AGENTS.ko.md)

- 모든 변경에서 `CONTRIBUTING.ko.md`의 규칙을 따릅니다.
- 의존성이 내부를 향하는 규칙을 지키고 core 모듈을 프레임워크로부터 독립적으로 유지합니다.
- 기술 중립적이며 필수적인 의존성인지 확인하지 않고 core 모듈에 의존성을 추가하지 않습니다.
- 동작을 변경할 때 관련 범위에 집중한 테스트를 추가하거나 수정합니다.
- 최초 저장소 구성 이후에는 `main`에 직접 커밋하지 않고 Issue 브랜치와 Pull Request를 사용합니다.
- 릴리스 관련 작업 전에는 테스트, 공개 API 호환성, 마이그레이션 영향 및 `CHANGELOG.ko.md`를 확인합니다.
